# 내 말투로 쓰기

김기강(Backend팀)이 동료에게 남기는 티켓 댓글·PR 코멘트·슬랙 공유 글을 본인 말투로 작성한다.

## 언제 쓰는가

- 티켓/PR/컨플루언스에 **댓글·답글·코멘트**를 남겨달라고 할 때
- 슬랙이나 문서로 **API 변동사항을 공유**해달라고 할 때
- 동료 질문에 대한 **답변을 정리**해달라고 할 때

쓰지 않는 경우: 커밋 메시지, PR description, 티켓 본문(주요 세부 정보), 코드 주석. 이건 별도 포맷이 있다.

## 절대 규칙 (과거에 직접 지적받은 것들)

1. **짧게.** 티켓 댓글은 3~6문장. 표를 쓰면 5행 이내. "너무 길어"는 가장 자주 나온 피드백이다.
2. **마크다운 강조 금지.** `**굵게**`, `###`, 불릿 장식 금지. 평문과 번호 목록만 쓴다.
3. **내부 라벨 금지.** "A안", "옵션 2", "G-3" 같은 나와 Claude만 아는 기호를 그대로 쓰지 않는다. 내용을 풀어쓴다.
4. **불필요한 영어·코드 덤프 금지.** 필드명·엔드포인트처럼 꼭 필요한 것만 남긴다. 스택트레이스, 파일 경로, 함수 시그니처는 넣지 않는다.
5. **한국어로 쓴다.** 영어로 정리됐으면 한국어로 다시 쓴다.
6. **게시 전 초안 확인.** 어떤 티켓에 어떤 내용을 남길지 먼저 보여주고 승인받는다. 여러 건이면 전체 목록을 한 번에 보여준다.

## 말투 핵심

지시 말투(반말)를 그대로 옮기지 않는다. **문장 구조와 어휘 습관은 유지하고 어미만 존댓말로 바꾼다.**

- 결론 먼저, 근거는 뒤에. 필요하면 첫 줄에 "결론부터"
- 한 문장에 한 가지. 접속사로 길게 잇지 않는다
- 조사 생략: "이 부분 확인 필요합니다" (○) / "이 부분에 대한 확인이 필요합니다" (△)
- 단정하지 않을 때는 "~할 것 같습니다", "~로 보입니다"로 낮춘다
- 내가 할 일은 "~하겠습니다"로 선언한다
- 부연·단서는 괄호로 뒤에 붙인다
- 인사말·맺음말 없음. 필요하면 마지막에 "확인 부탁드립니다" 한 줄

기준 샘플 (본인이 직접 불러준 문구):

```
해당 티켓은 FE에서도 작업이 되어야 확인할 수 있어 alpha3로 넘겨야할거 같습니다.
스프린트 변경해두겠습니다.
```

## 수신자별 조절

| 대상 | 사람 | 조절 |
|---|---|---|
| FE | 박정환, 양재민, 김남희 | 엔드포인트·파라미터·리턴 필드를 정확히. 표 사용 가능 |
| 기획/PM | 정재원, 오은지 | 비개발 용어. 무엇이 바뀌고 화면에 어떤 영향인지 중심 |
| QA | 김소희, 이지혜, SQA 그룹 | 무엇을 어떤 데이터로 어떻게 테스트하는지. 재현 조건 명시 |
| 코드리뷰 | 최인수 등 | 승인 근거만 짧게 |

태그가 필요하면 요청에 나온 이름을 그대로 쓴다. 임의로 추가하지 않는다.

## 작업 순서

1. 티켓/PR 내용과 기존 댓글을 먼저 읽는다 (`mcp__atlassian-agent__jira_get_issue`)
2. `references/style.md`의 변환 규칙과 예시를 적용해 초안 작성
3. 초안을 사용자에게 보여준다 — 어느 티켓에, 누구 태그해서, 어떤 내용인지
4. 승인 후 게시

**게시 경로:** Atlassian MCP는 읽기 전용이라 댓글 등록 툴이 없다. 초안을 코드블록으로 출력해서 붙여넣을 수 있게 한다. 등록까지 자동화하려면 `ATLASSIAN_API_TOKEN`을 받아 `POST /rest/api/3/issue/{key}/comment`를 쓰면 되지만, 요청받기 전에는 하지 않는다.

## 상세 규칙

어미 변환표, 어휘 목록, before/after 예시 16개는 `references/style.md`를 읽는다.

## 말투 갱신

말투가 변했다고 느껴지면 코퍼스를 다시 뽑아 `references/style.md`를 갱신한다.

```bash
python3 ~/.claude/scripts/extract-voice.py -o /tmp/corpus.json --text /tmp/corpus.txt
```
