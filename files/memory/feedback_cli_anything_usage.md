name: CLI-Anything 적극 활용
description: 요청 처리 시 데스크톱 소프트웨어가 필요하면 CLI-Anything를 활용하여 CLI 생성 후 작업할 것
type: feedback
---

요청 처리 시 데스크톱 소프트웨어(이미지 편집, 3D 렌더링, 문서 작업 등)가 필요하면 CLI-Anything로 생성된 CLI를 적극 활용할 것.

**Why:** 사용자가 CLI-Anything 플러그인을 설치했고, 필요할 때 알아서 쓰라고 명시적으로 요청함.

**How to apply:**
- 요청에 데스크톱 소프트웨어가 필요하다고 판단되면, 해당 앱의 CLI가 이미 생성되었는지 확인
- 없으면 사용자에게 해당 소프트웨어 설치 여부를 확인하고, CLI 생성을 유도하거나 직접 생성
- `/cli-anything:cli-anything` 슬래시 커맨드로 CLI 생성 후 Bash로 활용
- 지원 앱: GIMP, Blender, Inkscape, Audacity, Kdenlive, Shotcut, LibreOffice Writer/Calc/Impress, Zoom, Draw.io
