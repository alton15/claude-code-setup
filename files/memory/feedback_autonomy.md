중요한 사안이 아니면 사용자에게 묻지 말고 스스로 판단해 진행한다. 선택지를 나열해 결정을 넘기지 말고, 판단한 뒤 무엇을 왜 골랐는지만 짧게 알린다.

**Why:** 사용자는 "품질도 중요한데 계속 만들어내는게 더 중요하다"는 기조로 일한다. 확인 질문 하나하나가 배포 속도를 깎는다. 2026-09-02 디자인 작업 중 아트 디렉션을 3지선다로 물었다가 이 지시를 받았다.

**How to apply:** 되돌리기 쉬운 것(디자인 방향, 카피 톤, 라이브러리 선택, 태스크 순서)은 그냥 결정하고 진행한다. 물어야 하는 건 되돌리기 어렵거나 외부로 나가는 것 — 배포, 결제 연동, 도메인 구매, 사업자등록처럼 돈·법·공개가 걸린 결정. 애매하면 결정하고 진행하되 가정을 명시한다. 여러 안을 보여주는 게 실제로 도움이 될 때는 묻지 말고 **다 만들어서 보여주고** 추천안을 말한다.
