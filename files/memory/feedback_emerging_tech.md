---
name: 기술 선정 시 최신 도구 포함
description: 기술 스택 추천할 때 최근 등장한 유망 도구도 선택안에 포함할 것
type: feedback
---

기술 스택 추천 시 검증된 메이저 도구뿐 아니라 최근 나온 유망한 도구도 적절하다면 선택안에 포함할 것.

**Why:** 사용자가 Lightpanda 같은 신생 도구를 직접 물어봤을 때, 처음 추천에서 빠져 있었음. 새로운 도구가 성능/비용 면에서 큰 이점을 줄 수 있으므로 놓치면 안 됨.

**How to apply:** 기술 선정/스택 추천 시 웹 검색으로 최근 3개월 내 주목받는 도구를 확인하고, 적합하다면 장단점과 함께 선택안에 포함. 단, maturity/안정성 정보도 반드시 같이 제공할 것.
