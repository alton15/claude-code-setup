description: 작업 중 유용한 CLI 도구가 있으면 사용자에게 설치를 제안하고 CLI로 세팅해서 활용할 것
type: feedback
---

작업 중 CLI 도구가 있으면 더 효율적일 때, 사용자에게 설치를 제안하고 CLI 기반으로 작업할 것.

**Why:** 사용자가 CLI-first 워크플로우를 지향함. 필요한 도구는 brew 등으로 설치해서 CLI로 쓰는 방식을 선호.

**How to apply:**
- 작업 중 특정 CLI 도구가 있으면 더 빠르거나 나을 때 → "이거 설치하면 좋겠는데요" 식으로 제안
- GUI보다 CLI 도구 우선 추천
- 이미 설치된 도구(brew list 참고)는 적극 활용
- 예: JSON 작업 → jq, API 테스트 → httpie, 검색 → ripgrep 등
