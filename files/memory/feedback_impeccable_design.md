프론트엔드/UI 디자인 작업 시 ~/.claude/skills/에 설치된 impeccable 스킬을 적극 활용할 것.

**Why:** AI가 생성하는 프론트엔드 코드의 디자인 품질을 높이기 위해 사용자가 직접 설치를 요청함. 기본 AI 디자인 안티패턴(진부한 폰트, 빈약한 대비, 과도한 카드 중첩 등)을 방지.

**How to apply:**
- UI/프론트엔드 코드 작성 시 `frontend-design` 스킬 참조
- 디자인 검토 시 `/audit`, `/critique`, `/polish` 등 커맨드 활용
- 애니메이션 작업 시 `/animate`, 색상 작업 시 `/colorize` 등 상황별 스킬 사용
- 새 프로젝트 시작 시 `/teach-impeccable`로 디자인 컨텍스트 설정 고려
